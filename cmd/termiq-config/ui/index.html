TermiQ — Einrichtung

Postfach, Kalender und Modell verbinden. Alles bleibt auf diesem Rechner.

Postfach

IMAP über SSL. Bei den meisten Anbietern ist Port 993 richtig.

Kalender

CalDAV-Adresse, zum Beispiel https://sogo.example.de/SOGo/dav/.

Sprachmodell

Jeder OpenAI-kompatible Endpunkt — auch ein eigener Server im Haus.

Verhalten

Die Voreinstellungen sind bewusst vorsichtig gewählt.

Probelauf

Liest das Postfach und zeigt, welche Termine entstehen würden. Es wird nichts eingetragen und nichts verschoben.
